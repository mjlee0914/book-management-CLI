# book-management-cli
## 📌 과제 소개

- 파이썬 기초 문법을 바탕으로 사용자와 상호작용하는 **콘솔 프로그램(CLI)** 개발
- 주제: **도서 관리 시스템** 구현
- `input()` 기반 대화형 메뉴 설계 + 도서 등록/검색/대여 로직 직접 작성
- 학습 포인트: 자료구조 선택, 객체지향 설계, `uv`로 가상환경 구축 등 개발 전 과정

## 🎯 과제 목표

- [ ]  `input()`과 반복문으로 도서 관리 CLI 시스템 구축
- [ ]  `uv`로 가상환경 구축 후 VS Code·주피터 노트북과 연동
- [ ]  객체지향(OOP)으로 확장 가능한 도서 모델 설계
- [ ]  리스트·딕셔너리·집합을 상황에 맞게 선택해 데이터 관리
- [ ]  조건문+반복문으로 검사/검색/필터링 기능 구현
- [ ]  코드를 패키지·모듈 구조로 분리해 재사용성 확보
- [ ]  `try-except`와 디버깅으로 실행 오류 진단·수정

## 📁 제출 형식

**제출 파일명**

```
python_final_project_[수강생이름].zip
```

(프로젝트 전체 디렉터리를 포함하여 압축)

**필수 내부 구조**

```
python_final_project_[수강생이름]/
├── models/                   # 도서 객체 관련 모듈 폴더
│   ├── __init__.py
│   ├── base_book.py          # 상위 도서 클래스
│   └── specialized_books.py  # 하위 도서 클래스 (단행본, 전자도서 등)
├── utils/                     # 공통 유틸리티 함수 폴더
│   ├── __init__.py
│   └── helpers.py             # 입력 검증 및 포맷팅 등
├── main.py                    # CLI 메뉴 루프 및 프로그램 진입점
├── pyproject.toml             # uv 프로젝트 가상환경 설정 파일
└── uv.lock                    # 의존성 고정 락 파일
```

**결과물 위치**

- 로컬 저장소 내 독립된 프로젝트 루트 디렉터리에 위치
- 전체 디렉터리가 최상단에 고정된 단일 압축 파일(`.zip`)로 LMS 등록

## ✅ [필수] 구현 내용

| 항목 | 설명 |
| --- | --- |
| **환경 구성 및 패키지 모듈화** | `uv`로 독립 가상환경 생성, 의존성 lock 파일 지정. `models/`, `utils/`, `main.py`로 폴더 분리해 패키지 구조로 격리, VS Code에서 정상 작동 확인 |
| **대화형 콘솔 메뉴(CLI) 구축** | `main.py` 실행 시 `while`문 + `input()`으로 메뉴(①도서 등록 ②전체 도서 조회 ③도서 검색 ④대여/반납 처리 ⑤종료) 표시, 입력값에 따라 로직 분기 |
| **객체지향 구조화** | 기본 도서 속성(도서명/저자/ISBN 등)을 지닌 상위 클래스 정의 → 하위 클래스(일반 단행본, 전자도서 등) 상속. 프라이빗 변수로 접근 제어, 메서드 오버라이딩으로 상세 정보 표현 |
| **대여/반납 로직 및 자료구조** | 도서 상세 정보(딕셔너리), 고유 식별 번호 목록(집합) 활용. ISBN 입력 → 대여 가능 여부 확인 → 상태 전환 흐름 구현. 중복 ISBN·공백 등 유효하지 않은 입력 차단, 자료구조 선택 근거를 주석으로 명시 |
| **기본 예외 방어** | 메뉴 선택 등에서 문자 입력으로 인한 타입 오류(`ValueError` 등)로 프로그램이 강제 종료되지 않도록 `try-except` 적용 |

## 🌟 [심화] 구현 내용

| 항목 | 설명 |
| --- | --- |
| **대여 이력 관리 및 콘솔 통계 연산** | 대여·반납 시 발생 데이터(ISBN, 처리 시간 등)를 변경 불가능한 **튜플(Tuple)**로 묶어 **리스트(List)**에 순차 저장. CLI에 '통계 조회' 메뉴 추가 → 월간 대여 통계, 최다 대여 도서 목록 콘솔 출력 |
| **고급 예외 처리 및 유효성 검증** | 존재하지 않는 도서 반납 시도 등 실행 중 발생 가능한 예외 상황 처리 구조 구현. 로그 기록 또는 입력 단계 유효성 검증으로 오류 재발 방지, 디버깅 수정 내역을 주석으로 명확히 기록 |
